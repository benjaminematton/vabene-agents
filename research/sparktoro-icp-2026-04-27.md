## Comparison + key findings (across both runs)

### 1. The keyword cluster determines audience composition dramatically

Both audiences were auto-classified as "planners" by SparkToro, but their composition diverges sharply with vocabulary:

- **Run 1 vocabulary** (`buyout the bar`, `30th birthday`, `celebration dinner`, `birthday weekend`) → consumer-restaurant-discovery audience (Infatuation, Thrillist, SevenRooms-as-consumer-platform).
- **Run 2 vocabulary** (`private dining`, `private room`, `dinner party`) → venue-industry audience (Peerspace-as-supplier-tool, Tagvenue-as-industry-directory, Cvent, TripleSeat).

**Implication for VaBene user-facing copy**: lean on Run 1 vocabulary (`30th birthday`, `bar buyout`, `celebration dinner`, `birthday weekend`) and **avoid Run 2 vocabulary** (`private dining`, `private room`, `dinner party`) in any consumer-facing surface — those terms code as industry, not consumer. The recruiter DM templates and reddit-monitor draft templates should reflect this.

### 2. SevenRooms = consumer-side; TripleSeat = venue-side

Run 1 surfaces SevenRooms (consumer-vocabulary input). Run 2 surfaces TripleSeat (industry-vocabulary input). They live in the same buildings but serve different customers. The original "3-tier incumbent" framing oversimplified — see refined SevenRooms section above.

### 3. The bachelorette-positioning correction is empirically validated

`thebash.com` (the bachelorette / event-entertainment marketplace) appears at #4 affinity in Run 2 (industry audience) and is **absent from Run 1** (consumer audience). The Bash's audience overlaps with venue-industry pros, not with consumer celebration buyers. **Reinforces "celebration not bachelorette"** — The Bash isn't where SF self-host milestone celebrants are; it's where event vendors / planners go.

### 4. LinkedIn signal scales with industry-pro density

Run 1: +12.5%. Run 2: +16.3%. Adding industry vocabulary raised the LinkedIn signal — so the LinkedIn over-index IS at least partly industry-pro contamination, not pure ICP behavior. Re-reverses my previous reframe (see LinkedIn section in Run 1 above).

### 5. Reddit channel is robust across both vocabularies

Run 1: +5.8% to +6.4% range. Both well above US average. Channel-level Reddit validation holds regardless of which keyword cluster defines the audience. The existing `vabene-reddit-monitor` is fishing in the right pond.

### 6. Three supply directories are confirmed across both runs

**Peerspace, Partyslate, and Tagvenue** appear in BOTH runs (different ranks but consistently top-5 in Run 2 and present in Run 1). Strong empirical signal that's where SF venue inventory lives — solid foundation for Axis 2 supply enumeration.

### 7. There may be no clean keyword-only path to a pure-consumer audience on SparkToro

Both runs were auto-classified as "planners" audiences. SparkToro's audience-builder seems to systematically infer planner-intent from any celebration-related keyword cluster — there's no clean way to build "pure self-host celebrant" via these inputs. The closest approximation is Run 1 (consumer-anchored colloquialisms produce more consumer-restaurant-discovery audience), but it's not pure. **The remaining 3 free searches probably can't isolate the persona further; better to hold them and let Day-14 reddit-monitor yield-per-sub data answer "where does ICP actually behave" empirically.**
